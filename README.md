# Respan Gateway LLM Client Mock

This example demonstrates how a client application would interact with a hypothetical Respan Gateway for LLM management. It simulates sending a request to a unified gateway endpoint, abstracting away the complexities of direct interaction with various LLM providers. The script shows the structure of a client request and a mocked gateway response, highlighting the simplification of LLM interaction and potential gateway-provided insights like cost.

## Language

`python`

## How to Run

Save the code as `respan_client_mock.py` and run it from your terminal:
`python respan_client_mock.py`
